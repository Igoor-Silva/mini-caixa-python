
# Mini Caixa

Projeto desenvolvido em Python para praticar lógica de programação, estruturas condicionais, laços de repetição e manipulação de listas.

## Funcionalidades

- Adicionar produtos
- Informar preço e quantidade
- Validar nome, preço e quantidade
- Calcular o subtotal de cada produto
- Listar os produtos adicionados
- Calcular o total da compra
- Remover produtos da lista
- Atualizar a quantidade de produtos e recalcular o subtotal

## Tecnologias utilizadas

- Python
